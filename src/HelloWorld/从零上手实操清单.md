# 现代 C# 14 从零上手实操清单

## 第一阶段：基元类型、字面量与控制流（建立基本手感）

_目标：通过编写一段段真实运行的控制台代码，熟悉 C# 强类型体系与基础控制流。_

- **1.1 基础数值类型与字面量后缀**
  - 整型家族：`int` (32位), `long` (64位，后缀 `100L`), 无符号 `uint`/`ulong`。
  - 浮点与高精度：`double` (默认双精度), `float` (单精度，后缀 `3.14f`), `decimal` (金融高精度，后缀 `99.99m`，绝不丢精度)。
  - 布尔与字符：`bool`, `char` (单引号 `'a'`)。
- **1.2 变量声明与推导**
  - 显式类型 vs `var`（类型自动推导的时机）。
  - `default` 关键字（所有类型的零值，类比 Go 的零值）。
  - 常量 `const` 与不可变基础。
- **1.3 现代字符串核心操作**
  - 字符串基础：`string`（双引号 `""`）。
  - 插值字符串：`$"Hello, {name}!"`。
  - C# 现代多行原始字符串：`"""..."""`（无需任何转义，保留所有缩进与 JSON 格式）。
- **1.4 基础控制流手感**
  - 条件分支：`if-else` 与三元运算符 `cond ? a : b`。
  - 循环家族：`for`、`while`、`do-while`。
  - 迭代利器：`foreach`（历遍集合的核心工具，对标 Go 的 `for range` 与 JS 的 `for...of`）。
  - 流程打断：`break`, `continue`, `return`。
- **1.5 基础异常处理机制**
  - `try-catch-finally` 语法实战。
  - C# 特有的条件捕获：`catch (Exception ex) when (ex.Message.Contains("..."))`。
  - 对比 Go 的显式返回 `err != nil`，建立 C# 异常抛出与拦截感知。

## 第二阶段：函数、参数控制与空安全

_目标：学会怎么写出干净的函数，并理解 C# 独特的参数传递与空值防御。_

- **2.1 现代函数定义与表达**
  - 标准函数声明：修饰符、返回类型、方法名、参数列表。
  - 单行函数简写（表达式主体）：`int Add(int a, int b) => a + b;`（类比 TS 箭头函数）。
- **2.2 灵活的参数特性**
  - 默认参数值（可选参数）：`void Log(string msg, int level = 1)`。
  - 具名参数调用：`Log(level: 2, msg: "Error")`。
  - 参数修饰符：`out`（多值传出，类比 Go 多返回值）、`ref`（传指针引用）、`in`（只读引用传递）。
- **2.3 严格空安全（Nullable）与操作符**
  - 可空标记：`string`（绝对不为 null） vs `string?`（可能为 null）。
  - 安全导航操作符：`user?.Address?.City`。
  - 空合并操作符：`var name = input ?? "默认值";` 与 `input ??= "默认值";`。
  - 空宽恕操作符：`user!.Name`（告诉编译器“我担保它不是 null，别哔哔”）。

## 第三阶段：数据容器与切片操作

_目标：熟练使用日常必须的数组、列表与字典，掌握 C# 12+ 带来的革命性集合新语法。_

- **3.1 数组与全新集合表达式**
  - 现代统一初始化语法：`int[] numbers = [1, 2, 3];`。
  - 集合展开操作符：`int[] combined = [..a, ..b, 99];`（完全对标 TS 的 `...` 扩展符）。
  - 现代切片与索引：末尾倒数索引 `^1`（倒数第一个元素）与范围运算符 `1..^1`。
- **3.2 必须掌握的核心集合**
  - 动态数组：`List<T>`（日常开发 90% 场景使用，对标 Go 的 `[]T` 与 JS 的 `Array`）。
  - 键值映射：`Dictionary<TKey, TValue>`（对标 Go 的 `map[K]V` 与 JS 的 `Map`）。
  - 唯一集合：`HashSet<T>`（无序去重集合，对标 JS 的 `Set`）。
- **3.3 声明式数据查询（LINQ 入门）**
  - 方法链实战：`.Where()` (filter)、`.Select()` (map)、`.OrderBy()` (sort)、`.ToList()`、`.Any()` / `.All()`。

## 第四阶段：现代面向对象与数据建模

_目标：掌握现代 C# 的类定义，消灭繁琐样板，体会值类型与引用类型在内存中的差异。_

- **4.1 类（Class）与现代属性语法**
  - 现代自动属性：`public string Title { get; set; }`。
  - 只读初始化控制：`{ get; init; }`（仅在对象构建时可赋值）与 `required` 关键字（强制实例化必须提供）。
  - 主构造函数（Primary Constructor）：直接在类名后挂参数，消灭手写构造函数的啰嗦。
- **4.2 数据实体神器：`record`**
  - 一行代码定义强类型数据模型：`public record User(int Id, string Name);`。
  - 自动获得：值相等性比较（无需重写 equals）、调试友好的字符串输出。
  - 优雅的非破坏性修改：`var updated = user with { Name = "新名字" };`。
- **4.3 结构体（`struct`）与内存本质**
  - 栈分配与堆分配实操：`struct`（传值/深拷贝）与 `class`（传引用）行为对照。
  - 浅拷贝陷阱与只读结构体（`readonly struct`）。
- **4.4 接口（Interface）与契约**
  - 接口定义：`interface IRepository { Task SaveAsync(); }`。
  - 类对接口的实现与依赖倒置（对标 TS interface 与 Go 隐式接口的区别）。

## 第五阶段：现代高级控制与异步并发

_目标：打通高频现代特性，具备看懂并编写 Native AOT 高性能代码的能力。_

- **5.1 现代模式匹配（Pattern Matching）**
  - `switch` 表达式（告别老旧的 switch-case 语句）。
  - 类型匹配、属性模式匹配与关系模式匹配（如 `value is > 0 and <= 100`）。
- **5.2 异步编程基石（Async / Await）**
  - `async` / `await` 运行逻辑。
  - 异步任务载体：`Task`、`Task<T>` 与轻量无堆分配的 `ValueTask<T>`。
  - 协同取消信号：`CancellationToken` 实战（对标 Go 的 `ctx.Done()`）。
- **5.3 顶级语句（Top-level Statements）与本地函数**
  - 单入口直接裸写代码，无需被任何外部类名包裹。
